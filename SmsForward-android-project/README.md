# 문자 전달 앱 (안드로이드 전용)

등록한 발신번호에서 온 문자만, 등록한 2개 번호로 자동 전달하고 이력을 남깁니다.

## 동작
- 문자가 오면 발신번호를 확인합니다. (하이픈/공백, +82 표기는 같은 번호로 봅니다)
- 목록에 있는 발신번호의 문자만 받는 번호 1, 2로 전달합니다. 그 외 문자는 전달하지 않습니다.
- 전달 문자 형식: `[문자전달] 발신 010-xxxx-xxxx` + 줄바꿈 + 원문
- 받는 번호에서 온 문자는 다시 전달하지 않습니다. (무한 반복 방지)
- 전달 이력은 앱 화면 아래에서 확인합니다. (최근 200건)

## APK 만들기 (Android Studio 없이)
1. github.com에서 새 저장소(Repository)를 만들고 이 폴더의 파일을 모두 올립니다. (`.github` 폴더 포함)
2. 저장소의 Actions 탭 → "Build APK" → Run workflow
3. 끝나면 Artifacts의 `SmsForward-apk`를 내려받아 압축을 풀면 `app-debug.apk`가 나옵니다.

Android Studio가 있으면 이 폴더를 열고 Build → Build APK(s)로 만들 수도 있습니다.

## 폰에 설치하고 켜기
1. APK를 폰으로 옮겨 설치합니다. ("출처를 알 수 없는 앱" 허용 필요)
2. 앱을 한 번 열고 "권한 허용하기"를 누릅니다.
   - 허용 창이 안 뜨거나 막히면: 설정 → 앱 → 문자 전달 → 오른쪽 위 ⋮ → "제한된 설정 허용" 후 다시 시도
3. 발신번호(한 줄에 하나), 받는 번호 2개를 입력하고 "문자 전달 사용"을 켠 뒤 "저장"
4. "배터리 최적화에서 제외"를 눌러 허용합니다.

## 알아둘 점
- 일반 문자(SMS)만 전달합니다. 긴 문자가 MMS로 오는 경우나 카카오톡 알림은 전달되지 않습니다.
- 전달 이력의 "발송 요청 완료"는 폰이 문자를 보내도록 요청했다는 뜻이고, 상대 폰 도착까지 확인하지는 않습니다.
- 받는 번호로 보내는 문자는 통신사 요금제에 따라 문자 요금이 나갈 수 있습니다.
- 휴대폰 제조사에 따라 앱이 오래 꺼져 있으면 동작이 멈출 수 있습니다. 가끔 앱을 열어 상태를 확인해 주세요.
